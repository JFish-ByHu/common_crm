# 前端共享代码目录约定

本目录用于存放可被多个前端应用复用的源码。当前目录是共享源码分类目录；当某一部分需要独立发布、独立版本或被后端同时使用时，再将其演进为独立 workspace package。

| 目录     | 用途                                                | 不应放入的内容             |
| -------- | --------------------------------------------------- | -------------------------- |
| `api`    | 按业务域划分的接口请求、请求参数和响应适配          | 页面组件、页面状态         |
| `enum`   | 可复用的枚举和字面量常量                            | 带业务流程的逻辑           |
| `hooks`  | Vue 组合式函数，例如分页、权限、表格查询            | 只能服务单一页面的临时代码 |
| `styles` | 设计令牌、主题变量、通用样式、Element Plus 全局覆盖 | 页面专属样式               |
| `type`   | TypeScript 类型、接口和数据模型                     | 枚举实现、运行时代码       |
| `utils`  | 无 Vue 依赖的纯工具函数，例如日期、金额和数据转换   | API 请求、页面状态         |

## 页面目录约定

每个业务页面使用以下结构：

```text
src/views/<业务名>/
  index.vue              # 页面入口、路由页面与页面编排
  components/            # 仅服务于该页面的业务组件
  hooks/                 # 仅服务于该页面的组合式逻辑（需要时创建）
  types.ts               # 仅服务于该页面的类型（需要时创建）
```

页面内的组件优先使用 Element Plus。只有在两个或以上应用或页面复用后，才迁移到 `packages` 对应目录。
